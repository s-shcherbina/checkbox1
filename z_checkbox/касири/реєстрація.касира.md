#

Для реєстрації касира необхідно використовувати файловий ключ або печатку, отримані у вашому АЦСК. Ви можете завантажити вже наявний у вас ключ або скористатися рішенням від нашого партнера DepositSign.

Безкоштовний ключ від DepositSign
Це найшвидший спосіб почати роботу: хмарний КЕП випускається безкоштовно за 2 хвилини прямо в кабінеті Checkbox, без необхідності зберігати файли на комп'ютері.
Порада по DepositSign: Логін — латиницею, кодова фраза — УКРАЇНСЬКОЮ
Безкоштовні хмарні печатки DepositSign: реєструються на ЕЦП директора у кількості, рівній кількості кас клієнта.
Подання заявки
У розділі Касири натисніть Додати касира.
Оберіть Створити ключ DepositSign.
Заповніть дані: назва, унікальний логін (латиниця), пароль для входу, телефон, пароль до ключа та кодова фраза УКРАЇНСЬКОЮ.
Натисніть Продовжити.
Підпис запиту до ДПС. Оберіть зручний спосіб підпису:
📁 Файловий ключ: зчитайте файл та введіть пароль.
📱 Дія.Підпис: зчитайте QR-код.
🏦 SmartID: через додаток Приват24.
Пумб
Статус ключа зміниться на Верифікація.
Прийняття умов DepositSign
Оновіть сторінку. Статус зміниться на Потрібен підпис →.
Натисніть Погодитись і підписати та оберіть спосіб підпису договору.
Після синхронізації статус стане Відправити в ДПС →
Відправка касира в ДПС
Натисніть на чорну кнопку статусу. За необхідності підпишіть заяву ключем директора.
Статус зміниться на Токен отримано.
Зачекайте 5-10 хв та оновіть сторінку.

Реєстрація власним файловим ключем. Використовуйте наявний файл ключа (ПриватБанк, ДПС тощо) для реєстрації касира.
Завантаження та перевірка ключа
У розділі Касири натисніть Додати касира та оберіть Через ключ ЕЦП.
Оберіть ваш АЦСК, завантажте файл ключа та введіть пароль до нього.
Перевірте зчитану інформацію та натисніть Підтвердити.
Налаштування касира
Введіть Назву касира, Логін та Пароль для доступу.
Додатково активуйте Checkbox Підпис для автоматичного підпису чеків.
Натисніть Продовжити та підпишіть запит до ДПС вашим головним ключем

!!!Не забудьте після реєстрації натиснути чорну кнопку «Відправити в ДПС», щоб завершити процес.
