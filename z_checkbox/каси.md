Для реєстрації каси (ПРРО) необхідно, щоб у ДПС вже була зареєстрована ваша торгова точка (форма № 20-ОПП). 
ДПС присвоїть касі унікальний номер. Датою реєстрації вважається день присвоєння цього номера.

Щоб додати касу на Checkbox:
Перейдіть у розділ "Каси" та натисніть "Додати касу".
У вікні заповніть параметри:
Номер каси: встановлюється автоматично.
Торгова точка: оберіть адресу зі списку.
Тип ПРРО (обрати):
Стаціонарний: працює за конкретною адресою.
Пересувний: зареєстрований на авто, діє по всій Україні.
Каса самообслуговування: працює без касира.
Інтернет-торгівля: для сайтів та онлайн-магазинів.

Каси мають декілька статусів:
Активна
Створена на порталі або активована після синхронізації.

Деактивовано в ДПС
Каса повністю видалена клієнтом у ДПС.

Деактивовано користувачем 
Вимкнена в Checkbox, але продовжує функціонувати в ДПС.

Не активна
Синхронізована з ДПС. Потребує активації через "Дії".

Запит успішно відправлено! Статус зміниться на "На реєстрації в ДПС". Оновіть сторінку через 5-10 хвилин. Після успішної реєстрації статус стане Активна.


Дії з касами
• Видалити — відправити запит на видалення в ДПС.
• Токен Нової пошти — для API інтеграції з НП.(попередньо договір Nova Pay)
• Аварійне закриття — для кас у Kasa Manager.
• Логи активації — історія змін статусу каси.
(• QR код ключа — старий метод для моб. застосунку.)

!!! Рахунки клієнтів формуються за активні каси. Тому після синхронізації каса "не активна", щоб уникнути зайвих нарахувань за невикористовувані каси.
