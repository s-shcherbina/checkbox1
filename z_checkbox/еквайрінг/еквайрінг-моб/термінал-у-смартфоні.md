#

Tap to Phone або термінал у смартфоні — це рішення, яке дозволяє підприємцям приймати безконтактні платежі без необхідності в окремому POS-терміналі. Все, що потрібно — смартфон із підтримкою NFC та спеціальне програмне забезпечення.

Ця функція призначена виключно для роботи в мобільному застосунку Checkbox. У браузерній версії еквайринг «Термінал у смартфоні» не працюватиме!

Для використання терміналу в смартфоні необхідно завантажити на смартфон декілька застосунків:

Для всіх
Checkbox - програмний РРО

для Android
Ощадбанк,ПУМБ,monobank - tapXphone (monobank - Термінал by mono(для першого налаштування))
ПриватБанк - Термінал (від ПриватБанк)
àбанк - àPay

для IOS
monobank - Термінал by mono
ПриватБанк - Термінал (від ПриватБанк)

monobank
Зверніть увагу!. При створені Терміналу в Смартфоні в бізнес кабінеті моно, вам буде запропоновано обрати операційну систему (iOS/Android) на якій плануєте використовувати Термінал в Смартфоні. При створені терміналу для Аndroid його не можливо буде налаштувати для роботи на iOS і навпаки.
