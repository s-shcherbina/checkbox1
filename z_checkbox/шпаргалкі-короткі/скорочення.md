КЕП - кваліфікований електронний підпис. 
Запроваджено Законом України «Про електронні довірчі послуги», замінило поняття ЕЦП;
ЕЦП - електронний цифровий підпис;

Дані ЕПЗ - дані електронного платіжного засобу.
  1. Це дані про оплату в термінальному сліп-чеку після оплати карткою.
  2. Слугують для ідентифікації грошової транзакції.

  • ЕПЗ — електронний платіжний засіб.
  • Сліп-чек — підтвердження транзакції з терміналу.

Еквайринг
Спосіб прийняття безготівкової оплати з банківської картки.
  • Tap to Phone — термінал у смартфоні через NFC.
  • Модуль NFC — "електронне рукостискання" пристроїв.
  • Інтернет-еквайринг — прийом оплат без заліза (API/CMS).

Білінг
Автоматизована система розрахунків.
  • Білінговий день — день реєстрації першої каси.
  • Білінговий період — місяць від дати до дати.

Фронт-система / Облік
Програма для ведення бізнесу: товари, чеки, зміни. Вона передає дані в Checkbox, а той — в ДПС.

• Запит JSON — команда (напр. на чек) у спец. форматі по API.
• Device ID — прив'язка каси до пристрою (ПК/застосунок).

Токен
Індивідуальний ключ захисту для обміну інформації. Спеціальний "квиток", який дозволяє доступ без повторного пароля. Виглядає як набір символів.

API
Набір інструкцій, який дозволяє одній програмі "спілкуватися" з іншою.
