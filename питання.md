# Питання

сайт чекбокс (портал) - це хмарна фронт-система?
як можна підʼєднати POS термінал до порталу, куди встановити Paylink на будь-який комп і поєднати термінал через Wi-FI або USB дріт.
як можна підʼєднати Android термінал до порталу, куди встановити Aircheck на будь-який комп і поєднати термінал через Wi-FI або USB дріт.

чи можливо перейти в офлайн режим при роботі на порталі? як це зробити.
краще закрити зміну на порталі checkbox в браузері смартфона, чи одразу можна працювати через застосунок IOS чи ANDROID (мобільн інтернет потягне портал).

закриту зміну
як перед закриттям зміни потрібно впевнитись, що всі минулі транзакції зміни мають кінцевий статус DONE
