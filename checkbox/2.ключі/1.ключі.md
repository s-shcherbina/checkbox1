# Ключі

⚠️Файловий ключ зберігається на носії, «має файл», хмарний - зберігається на хмарному сховищі АЦСК.
🚨Зареєструвати касира на хмарний ключ неможливо (окрім ключа від наших партнерів ⚠️DepositSign).

⚠️КЕП (ЕЦП)– ключ, який належить конкретній особі. Тільки ця особа може його використовувати;
⚠️Печатка – ключ, який належить компанії. Під ним можуть працювати різні люди.

⚠️Хмарні ключі часто потребують повторного сканування QR-коду. Тому якщо клієнт стикається із тим, що потрібно декілька раз відсканувати код при підписі SmartID або ключем Дії, радимо сканувати поки документ не буде підписано.

☝Як перевірити ключ через сайт АЦСК?
💡Переходимо на сайт потрібного нам АЦСК;
💡Вказуємо у відповідне поле ЄДРПОУ/ІПН клієнта;
💡Завантажуємо сертифікат ключа, відкриваємо файл та переглядаємо ідентифікатор ключа у вкладці «Докладно»;
💡Використовуємо ідентифікатор, щоб звірити, чи справді цей ключ належить зареєстрованому в Checkbox касиру.

☝Як дізнатися актуальний ключ директора?
💡Клієнт переходить у кабінет платника податків;
💡Натискає на своє ім’я справа згори;
💡Переходить в «Налаштування» - «Дані про уповноважених осіб»;
💡На екрані з’явиться термін дії та ідентифікатор головного ключа директора.

⚠️Розширення популярних ключів
Приватбанк - JKS;
АЦСК Україна - ZS2;
Ключі ДПС - DAT;
Ключі Ощад – PFX (🚫не можна реєструвати касира, ⚠️можна використовувати для підпису 20-ОПП чи 1-ПРРО);
Ключі monobank - PFX(⚠️можна використовувати і для підпису 20-ОПП чи 1-ПРРО і реєструвати касира);
Печатка ДПС - PFX.

⚠️<https://ca.diia.gov.ua/certificates-search> - Сайт Дії для перевірки ключа
Посилання на цей сайт можна надавати для клієнтів.
Він призначений для перевірки сертифікатів ключів ЕЦП:
Цей інструмент дозволяє перевірити, чи є сертифікат електронного підпису дійсним.
Ви можете знайти інформацію про видані сертифікати, термін їх дії, статус (дійсний, скасований, заблокований тощо).
ВАЖЛИВО! Перевірку клієнт повинен виконувати САМОСТІЙНО! Жодних файлів ключа, паролю і т.д. отримувати від клієнта ЗАБОРОНЕНО!

🚨Ключі на які не можна реєструвати касира
🚫Ключі ОщадБанку. Зверніть увагу, що у Ощадбанку немає файлових ключів. Те, що ОщадБанк надає клієнтам - це СЕРТИФІКАТ формату pfx; ловимо помилку http (5) ⚠️Ключі monobank pfx можна!
🚫Ключі Sense банку, ловимо помилку http (5)
🚫Ключі УкрсибБанку теж можна використовувати лише для підпису заяв до ДПС. Як ключ касира використовуватись не може.
🚫ПУМБ (хмарний);
🚫Хмарний підпис SmartID;
🚫Хмарний підпис Дія.Підпис. (для ФОП)

⚠️Саме тому, коли клієнт зчитує сертифікат на порталі для реєстрації чи підпису 20-ОПП чи 1-ПРРО - все ок.
Але запустити сертифікат на Чекбокс підпис - неможливо. Аналогія з ключем Smart Id від привату. Ключ не файловий, а зберігається десь у хмарі.
